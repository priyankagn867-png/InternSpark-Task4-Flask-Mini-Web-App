# Task 4 — Flask Mini Web App

A small Todo application demonstrating:

- Flask routing
- Jinja templates
- Bootstrap UI
- SQLite database
- Create, read, update (toggle), and delete operations
- Form handling and flash messages

Run:

```bash
pip install Flask
python app.py
```

Open:

http://127.0.0.1:5000

The SQLite database is created automatically on first run.
